## Exact counterexample

Let `{Pbar_kappa}` be any collection of extended ten-wedge Toller-sector functionals satisfying

`sum_(kappa in {+,-}^10) Pbar_kappa = A_EPRL`.

Choose one factorized causal sector `s` and any distinct sector `t`. For any nonzero gauge-invariant boundary functional `ell in H_B^*`, define

`Pbar'_s = Pbar_s + ell delta_N`,

`Pbar'_t = Pbar_t - ell delta_N`,

with all other sectors unchanged.

Then:

1. both modified sectors are identical to their original source Toller products off the common-collision set `N`;
2. `ell delta_N` has transverse scaling degree 12, so adding/subtracting it remains within the same finite-scaling-degree extension class controlled by Iter077L;
3. the unconstrained sector sum is exactly unchanged because the two supported shifts cancel algebraically;
4. the selected factorized causal-sector extension changes whenever `ell != 0`;
5. the primary source supplies no sector-by-sector collision normalization forbidding this compensating supported shift.

Therefore the exact EPRL recovery constraint fixes only a combination of sector extensions, not the individual causal one.

The finite/defined EPRL vertex cannot be used as a hidden normalization condition that retroactively selects the causal-Toller K5 extension. Even imposing the exact `T+ + T- = D` identity after extension leaves a nontrivial kernel of compensating supported shifts.
