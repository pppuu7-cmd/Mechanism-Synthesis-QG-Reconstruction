## exact OBJECT

For each proper orbit representative `Z` and each frozen weight vector `W`, define the exact linear corner path

`alpha_e(t) = W_e t` for `e in Z`,

`alpha_e(t) = W_e` for `e not in Z`.

`U_Z^W(t) = U_Z(alpha(t)) = sum_(n=0)^5 u_(Z,W,n) t^n`.

The gate records the exact first nonzero order `r_U=min{n:u_n != 0}` or exact zero if all six coefficients vanish. It does not evaluate `N_c`, `B_v[N_c]`, an integrated period, or a physical corner exponent.
