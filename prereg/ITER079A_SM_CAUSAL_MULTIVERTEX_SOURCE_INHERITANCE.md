# Iter079A-SM preregistration — source-faithful causal multi-vertex inheritance

**Date:** 2026-09-14

## HYPOTHESIS

The post-Iter078A source record, including Beltrán `arXiv:2603.22661v2`, may now supply enough source authority to define a causal-Toller amplitude on a nontrivial multi-vertex 2-complex without silently importing a noncausal EPRL/BF prescription. This gate tests that possibility prospectively.

## EXACT OBJECT

A minimal source-faithful causal multi-vertex spinfoam functional built from the Bianchi–Chen–Gamonal (BCG) Toller vertex on an oriented 2-complex, with the local K5 distributional ambiguity of Iter077L/M/Q explicitly retained rather than ignored.

The object is not the fixed-all-`j=1/2` order-zero surrogate and not an Ooguri/BF recurrence.

## DEPENDENCY TESTED

Whether CRQN can move from a source-defined local causal vertex to a mathematically defined composition/gluing layer capable, in principle, of acting on the Iter077Q extension function space.

## FROZEN SOURCE AUTHORITY

1. E. Bianchi, C. Chen, M. Gamonal, `Causal spinfoam vertex for 4d Lorentzian quantum gravity`, arXiv:2601.23162, current source version used by repository authority.
2. E. Bianchi, C. Chen, M. Gamonal, `Toller matrices and the Feynman i epsilon in spinfoams`, arXiv:2604.24945.
3. C. E. Beltrán, `Causal Structure for Generalized Spinfoams`, arXiv:2603.22661v2 (3 Aug 2026).
4. Standard EPRL/EPRL-KKL state-sum/composition structure may be used only where the causal source explicitly inherits it or where an exact bridge is derived. It may not be imported silently.
5. Repository authorities Iter077K/L/M/N/Q and Iter078A remain controlling for the local distributional object and previous map blocker.

## FROZEN REQUIRED ELEMENTS

The minimal multi-vertex physical object is considered defined only if all of the following are source-explicit or theorem-derived without new post-hoc choices:

`E1` oriented 2-complex causal structure and compatibility of edge/face orientations across shared cells;

`E2` local causal Toller vertex on each vertex boundary graph for arbitrary required valence;

`E3` full multi-vertex state-sum/composition rule: how local causal vertices are multiplied/contracted over internal data;

`E4` internal face/edge weights and spin/intertwiner sums appropriate to the causal model, including normalization conventions;

`E5` boundary gluing / Hilbert-space contraction with orientation/dual conventions fixed;

`E6` gauge fixing / treatment of redundant noncompact group integrations for the composed causal object;

`E7` a joint distributional/regulator prescription sufficient to make every local causal vertex and the composed object a well-defined functional in the presence of the Iter077I/K/L/Q collision singularity;

`E8` an explicit rule transporting/projecting the local supported extension freedom, including the Iter077Q tangential coefficient functions, through gluing/composition;

`E9` for refinement/RG use, a coarse/fine boundary embedding/projection or matching functional. E9 is not required merely to define a fixed multi-vertex amplitude, but is required before calling the object a refinement/RG map.

## FROZEN STATUS LABELS PER ELEMENT

Each element must receive exactly one label:

- `SOURCE_EXPLICIT`: directly specified in frozen source authority;
- `SOURCE_INHERITED_WITH_EXPLICIT_BRIDGE`: inherited from EPRL/EPRL-KKL with an explicit causal-source statement or derivation showing the inheritance;
- `THEOREM_DERIVED`: follows from already authoritative repository/source theorems without adding a new physical choice;
- `MISSING_REQUIRED_OBJECT`: no source-faithful definition/bridge is available;
- `CONFLICTED`: frozen sources give incompatible prescriptions;
- `NOT_REQUIRED_AT_THIS_LAYER`: only allowed for E9 when classifying a fixed multi-vertex amplitude rather than RG/refinement.

## POSITIVE CONTROLS

- BCG source explicitly starts from spinfoams on 2-complexes and causal edge orientations, while then specializing its constructed Toller amplitude to a single 4-simplex vertex.
- Beltrán v2 must independently recover an arbitrary-2-complex causal structure and a generalized BCG/Toller vertex if the source audit is correct.
- The one-wedge Toller i-epsilon / Toller-function object must remain source-defined.

## NEGATIVE CONTROLS

- An ordinary EPRL or BF product/face measure without an explicit causal inheritance bridge is `MISSING_REQUIRED_OBJECT`, not a PASS by analogy.
- A generalized *vertex* on a vertex of an arbitrary 2-complex does not by itself prove a complete multi-vertex distributional functional.
- Semiclassical multi-vertex motivation does not define finite-spin extension transport or regulator independence.
- The fixed-spin order-zero Iter078 controls cannot stand in for E3–E8.

Freeze exact source statements for the original single-vertex construction, one-wedge Toller prescription, and the explicit distinction between unrestricted EPRL wedge-sign sum and constrained causal structures.

## PASS

PASS for `MULTIVERTEX_OBJECT_DEFINED` only if E1–E8 are all `SOURCE_EXPLICIT`, `SOURCE_INHERITED_WITH_EXPLICIT_BRIDGE`, or `THEOREM_DERIVED` and no conflict remains.

## FAIL

FAIL only if frozen source prescriptions are mutually inconsistent in a way that makes the proposed causal multi-vertex object impossible under their stated assumptions. Mere absence of a definition is not FAIL.

## BLOCKED

BLOCKED if at least one of E1–E8 is `MISSING_REQUIRED_OBJECT` while no contradiction is proven.

If E1/E2 are newly source-defined but E3–E8 remain incomplete, the required classification is a scoped partial bridge plus `BLOCKED_MULTI_VERTEX_CAUSAL_OBJECT_DEFINITION`; the result must explicitly state which old Iter078A missing items were resolved by the new source.

## INVALID

INVALID for importing BF/EPRL weights, regulator, extension, boundary map or refinement map without an explicit causal bridge; using a surrogate; treating semiclassical evidence as exact finite-spin definition; or changing the required-element list after source audit.

## INTERPRETATION CEILING

A PASS would define only the causal multi-vertex composition object. It would not prove unique K5 extension, regulator independence, RG fixed point, continuum limit, G3, GR recovery or complete QG.

A BLOCKED result does not prove no causal multi-vertex completion can exist. It identifies the exact remaining model-defining objects that CRQN v0.2 lacks and prevents downstream RG/G3 promotion until a prospectively motivated bridge supplies them.
