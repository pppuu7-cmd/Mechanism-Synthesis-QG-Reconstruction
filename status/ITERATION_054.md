# Iteration 054 — preregistration: sign-compatible K4 affine contour chambers

**Date:** 2026-09-12

## Motivation

Iter052 closed the fixed canonical antisymmetry-cancellation branch. Iter053 independently tests the narrow equal-magnitude common translation condition `A v=s`. Iter054 prospectively tests a broader but still sharply defined affine-contour question without waiting for or adapting to Iter053 output.

For one K4 tree/cycle basis write `x_e=b_e+a_e·y`. A common affine contour direction `v` preserves the required causal Feynman sign on every edge, while allowing edge-dependent positive magnitudes, iff

`s_e (a_e·v) > 0` for all six edges.

With `M = diag(s) A`, this is the exact strict system

`M v > 0`.

This does **not** fit six independent shifts: one common three-vector `v` is still required. Only the positive magnitudes generated by that one vector may differ across edges.

## Exact theorem used

By strict separation / Gordan's theorem, `M v>0` is feasible iff zero is not in the convex hull of the six row vectors of `M`. In three dimensions, Carathéodory's theorem guarantees that convex-hull obstruction can be witnessed by at most four rows.

Implementation must therefore decide feasibility exactly by enumerating all affinely independent row subsets of size 1–4 and testing for an exact nonnegative convex combination equal to zero. No floating threshold determines the classifier.

For a feasible lane, implementation must additionally find a small integer witness `v` by a deterministic bounded search and verify all six inequalities exactly. Failure to construct/verify a witness after the exact feasibility decision is an invalid implementation lane, not a scientific FAIL.

No gamma, epsilon or external-flow scan is relevant because the strict sign chamber depends only on graph/cycle geometry and the causal sign vector.

## Frozen lane outputs

For every `(sign_class, tree)`:

1. exact `A` and `M=diag(s)A`;
2. exact cycle-space/reconstruction checks;
3. exact boolean `strict_sign_chamber_feasible`;
4. if infeasible: a Carathéodory/Gordan obstruction certificate (edge subset and nonnegative rational weights summing to one with weighted row sum exactly zero);
5. if feasible: a deterministic integer witness `v` with all six exact signed dot products strictly positive;
6. minimum exact signed margin for the chosen witness;
7. all validity checks fail closed.

## Frozen aggregate classifiers

- `ITER054_RECONSTRUCTION_OR_CERTIFICATE_INVALID` if any lane fails graph/basis reconstruction, exact obstruction verification, or exact witness verification.
- `K4_CAUSAL_SIGN_CHAMBER_ALL_CLASSES_FEASIBLE` iff all eight causal sign classes are feasible in every tree basis.
- `K4_CAUSAL_SIGN_CHAMBER_CLASS_DEPENDENT` iff at least one but not all sign classes are feasible, with per-class feasibility identical across all four tree bases.
- `K4_CAUSAL_SIGN_CHAMBER_NO_CLASS_FEASIBLE` iff none is feasible and all exact obstruction certificates/basis checks pass.

These classifiers are frozen before implementation/output.

## Claim locks

A feasible chamber means only that one common affine contour direction can generate the six **signs** with generally unequal positive magnitudes. It does not reproduce the original equal-magnitude `epsilon` prescription unless Iter053 also establishes `A v=s`.

An infeasible class means only that no one-vector affine translation can realize all six causal signs for that class. It is not a no-go theorem for correlated edge-dependent contour deformations, nonlinear contours, Jeffrey–Kirwan/Grothendieck residue prescriptions, or the physical causal vertex.

No K5, G3, F9, G8 or new-physics promotion is permitted from this gate.
