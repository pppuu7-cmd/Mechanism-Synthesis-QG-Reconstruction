# Iteration 053 — preregistration: global K4 causal-contour compatibility

**Date:** 2026-09-12

## Motivation

Iter052 terminally rejected the fixed canonical S3 triple-residue antisymmetry identity. The next permitted direction is not coefficient fitting but a source/analyticity-selected simultaneous multivariate K4 audit.

The frozen K4 kernel uses six causal denominators

`x_e(y,k) - i s_e epsilon`,

where the six edge flows `x_e` are affine functions of three independent cycle variables `y=(y0,y1,y2)` and `s_e=±1` is the factorized causal sign. Write

`x_e(y,k) = b_e(k) + a_e · y`.

A **single uniform global translation** of the three-dimensional cycle contour,

`y -> y - i epsilon v`,

reproduces all six frozen Feynman shifts exactly iff

`A v = s`,

with `A` the exact 6×3 matrix whose rows are `a_e` and `s` the six-edge causal-sign vector.

This is a necessary-and-sufficient test only for this narrow common-translation realization. It is not a test of all possible multivariate contours.

## Frozen matrix

- all 8 factorized K4 causal sign classes from `SIGMA_CLASSES`;
- all 4 existing unimodular K4 tree/cycle bases `S0,S1,P0,P1`;
- total: **32 exact lanes**.

No gamma, epsilon or external-flow scan is needed: `A v=s` depends only on graph/cycle geometry and the frozen causal sign vector. Each lane must nevertheless reconstruct the exact K4 incidence/cycle relations.

## Exact lane outputs

For each `(sign_class, tree)`:

1. exact 6×3 cycle coefficient matrix `A`;
2. exact rank `rank(A)` and augmented rank `rank([A|s])`;
3. exact solution of `A v=s` when it exists;
4. exact residual for a deterministic least-subset candidate when no solution exists;
5. graph-space check `B s`, where `B` is the K4 incidence matrix;
6. exact equivalence between `A v=s` solvability and membership of `s` in the cycle space represented by `A`;
7. reconstruction checks for every edge-flow coefficient row.

## Frozen aggregate classifiers

- `ITER053_RECONSTRUCTION_OR_BASIS_INVALID` if any exact graph/cycle reconstruction or basis-invariance consistency check fails.
- `K4_CAUSAL_SHIFTS_GLOBAL_UNIFORM_CONTOUR_COMPATIBLE` iff **all eight** causal sign classes admit `A v=s` in every tree basis and solutions transform consistently between bases.
- `K4_CAUSAL_SHIFTS_GLOBAL_UNIFORM_CONTOUR_CLASS_DEPENDENT` iff at least one but not all sign classes are globally compatible, with compatibility identical across all four tree bases for each sign class.
- `K4_CAUSAL_SHIFTS_NO_GLOBAL_UNIFORM_CONTOUR_TRANSLATION` iff none of the eight causal sign classes admits `A v=s` in any tree basis and all basis checks agree.

These classifications are frozen before implementation/output. No alternative edge weights, nonuniform epsilon magnitudes, nonlinear contour, fitted deformation vector, counterterm or preferred tree may be introduced after seeing the result.

## Interpretation locks

A FAIL of common translation means only that the six causal shifts cannot be generated by one **uniform affine translation** of the three cycle variables. It is **not** a no-go theorem for general correlated contours, Jeffrey–Kirwan/Grothendieck residue prescriptions, source-defined distributional extensions, or the causal vertex.

A PASS would establish only this exact contour-compatibility property. It would not establish amplitude finiteness, K5, G3, F9, G8, or new physics.
