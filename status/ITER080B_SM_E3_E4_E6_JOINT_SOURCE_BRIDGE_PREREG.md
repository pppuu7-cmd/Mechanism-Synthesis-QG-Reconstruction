# Iter080B-SM — Joint E3/E4/E6 generalized-causal source-bridge audit (preregistration)

Date frozen: 2026-09-14

## Question

Does the already validated primary-source corpus (parent KKL/EPRL + Bianchi–Chen–Gamonal 2601.23162 + Beltrán 2603.22661v2) explicitly authorize a **complete many-vertex causal prescription** in which all three parent structures are inherited unchanged under the causal/Toller local-vertex replacement:

- E3: inter-vertex/boundary contraction or pairing used in gluing;
- E4: face/edge weights, internal representation/intertwiner sums, and normalization outside the local vertex;
- E6: per-vertex noncompact `SL(2,C)` gauge quotient/fixing normalization.

This is a source-definition audit. It does not test E7/E8, does not define a K5 extension, and cannot promote G3/F9/G8.

## Frozen source corpus

1. Parent KKL/EPRL composition/gluing authority already recorded in Iter079B/E/G/K/L durable results.
2. Bianchi–Chen–Gamonal, arXiv:2601.23162, causal EPRL vertex paper.
3. Beltrán, arXiv:2603.22661v2, generalized causal EPRL-KKL vertex paper.

No later source may be added after implementation solely to rescue a failed criterion. A later source requires a new gate.

## Frozen predicates

A source counts as a **complete bridge** only if the corpus explicitly states or derives all of the following for a many-vertex causal foam, not merely for one local vertex:

P1. The causal amplitude is defined on a multi-vertex / arbitrary-2-complex state sum or transition amplitude, rather than only a local vertex building block.

P2. E3 inheritance is explicit: the parent KKL gluing/contraction/pairing is retained unchanged (or an explicit causal replacement is supplied).

P3. E4 inheritance is explicit: parent face/edge weights, internal sums and normalization are retained unchanged (or explicit causal replacements are supplied).

P4. E6 inheritance is explicit: the parent per-vertex noncompact `SL(2,C)` quotient/fixing prescription and its normalization are retained/derived for the multi-vertex causal functional.

P5. The prescription is compatible with the causal/Toller local vertex actually defined by BCG/Beltrán, not a different causal spin-foam model.

## Frozen evidence anchors

- BCG explicitly says it focuses on the amplitude of a **single vertex**, describing it as a building block for a many-vertex path integral; it discusses many-vertex construction as future work.
- Beltrán defines causality on arbitrary 2-complexes and a generalized **causal vertex amplitude**, while explicitly listing finiteness of that generalized causal vertex as an open question.
- Parent KKL structures can therefore be algebraically conditionally inherited under a strict vertex-only replacement, but such algebraic inheritance is not itself source authorization of a complete causal many-vertex prescription.
