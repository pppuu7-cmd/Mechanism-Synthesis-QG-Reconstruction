# Mechanism-Synthesis QG Reconstruction (MSQGR)

**Status:** ACTIVE RESEARCH PROGRAMME — candidate architecture only; no claim that quantum gravity is solved.

MSQGR is a fourth, deliberately independent reconstruction route for quantum gravity. Instead of selecting a school or searching first for one universal inter-school parameter, it decomposes established quantum-gravity programmes into physical mechanisms, normalizes equivalent mechanisms, measures recurrence and compatibility, and then synthesizes the smallest non-redundant candidate architectures that survive hard consistency gates.

## Core question

> If the major quantum-gravity families are decomposed into their operative physical mechanisms, which mechanisms recur independently, which supply complementary functions, and which combinations can coexist in one mathematically coherent Lorentzian quantum theory with a controlled GR/QFT infrared limit?

## Distinction from the neighbouring programmes

- **QGR / KMQGB route:** candidate pressure comes from benchmark failures and missing closure.
- **RQIR-Candidate-Gravity:** candidate is reconstructed directly from the frozen RQIR funnel.
- **Inter-School QGR:** searches primarily for common cross-school structures/parameters.
- **MSQGR:** decomposes schools into mechanisms, classifies each mechanism by role, constructs a compatibility graph, and synthesizes minimal candidate architectures.

The four routes must remain sufficiently independent that later convergence is informative rather than engineered.

## Non-negotiable anti-Frankenstein rules

1. **Mechanisms, not names.** `LQG`, `CDT`, `GFT`, `causal sets`, `asymptotic safety`, `strings/holography`, etc. are source families, not building blocks.
2. **Origin vs transport must be separated.** A mechanism that only transports or constrains constitutive data cannot be promoted to the microscopic origin of those data.
3. **No voting theorem.** Recurrence across schools raises priority; it does not make a mechanism true.
4. **Compatibility before synthesis.** Ontology, symmetry, Hilbert/state space, dynamics, causality, locality and continuum limits must be checked pairwise and globally.
5. **Minimality.** Every retained mechanism must remove a documented failure mode. If deleting it changes nothing essential, it is decorative and is removed.
6. **Same-realization discipline.** UV completion, causal structure, observables and IR recovery must arise from one linked realization; successes imported from mutually unrelated realizations do not add.
7. **Fail closed.** Unknown compatibility is `BLOCKED`, not `PASS`.
8. **No retrofitting the judge.** RQIR/KMQGB constraints are external evaluation layers and are not tuned to rescue an MSQGR candidate.
9. **No overclaim.** A candidate architecture is not a theory until its microscopic dynamics, measure/state space, observables, continuum limit and quantum consistency are explicit.

## Pipeline

`families -> mechanism decomposition -> normalization -> role classification -> recurrence graph -> compatibility matrix -> minimal set cover -> candidate architectures -> bridge equations -> ablation -> RQIR/KMQGB evaluation`
